# alpha-composite-stack — preset card

Three alpha layers (background, mid, foreground) composited through per-layer
opacity and a clip mask; the foreground sits inside a rounded shape derived from
the source.

Aliases: layer-stack, alpha-stack.

Required: ClippingMaskNode, OpacityNode, BlendModeNode.

Best for: multi-layer UI mockups, hero illustrations, before/after overlays.
